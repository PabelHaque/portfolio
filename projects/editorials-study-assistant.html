Case study 03 · LLM pipeline & data engineering

Autonomous Exam-Study Intelligence Platform

Candidates for Bangladesh's civil-service and bank exams need the day's editorials mapped to a syllabus — and get a firehose instead. This pipeline reads the sources overnight, scores every article 0–100 for exam readiness, keeps the argument for why a foreign story matters here, and serves what survives through an 18-page study workspace. It runs on free-tier and local models; the paid route stays off until someone flips it.

The problem

The raw material is public: op-eds, business analysis, global geopolitics coverage. Maybe one article in ten is usable, and finding it costs an hour a day of the attention that should be going into studying.

A naive scraper makes it worse — a firehose of lifestyle pieces, sports columns and foreign coverage with no bearing on the syllabus. The value is entirely in the discarding.

The relevance gate

Deterministic taxonomy first, LLM second.

A deterministic topic taxonomy maps each article against syllabus themes; only then does the LLM assign a strict 0–100 exam-readiness score. Articles below the threshold never enter the main study queue — they go to a rejected-article log, so a bad filtering decision is auditable rather than invisible.

Putting the cheap deterministic pass first is not only a cost decision. The model scores within a known topic frame rather than inventing one per article, which is what keeps scores comparable across a corpus that grows nightly.

The rule that makes foreign coverage useful International sources are held to a stricter bar: the model must identify a concrete Bangladesh connection before an article is kept. Each survivor stores that reasoning in its own fields — issue tags, the Bangladesh link analysis, impact points, response strategy — so a candidate gets the argument, not just the headline.

The detail I would defend in an interview

A model router with a real fallback chain — free and local tiers first.

Every LLM call goes through a shared router with an ordered fallback chain: free-tier hosted open-weight routes first, then a second independent free-tier provider serving the same open-weight model, then local models. It advances down the chain on a rate limit, a daily quota exhaustion, invalid JSON in the response, an unavailable model, or a local server that is not running.

  • Paid routes are off by default behind an explicit opt-in flag. Cost cannot escape by accident.
  • Provider independence. The second provider serves the same open-weight model, so exhausting one daily quota degrades throughput, not output quality. With only the second key present, the router picks it directly.
  • Invalid JSON is a routing signal, not a crash. Treating a malformed structured response like an outage is what keeps an overnight crawl from dying at 2am on one bad generation.
  • Named presets — best quality, fastest, Bangla-capable — so the operator picks an intent, not a model identifier.

A corpus that predates its own scoring

Relevance scoring did not exist in the first version, so a body of articles had no score. Deleting them discards real content; scoring them zero hides it; pretending they were scored corrupts the comparison. They are marked legacy and backfilled at a neutral value until rescore_articles.py recalculates them against the current gate. The state is visible in the data rather than papered over.

Beyond the crawler

Past exam questions come in from three directions because no single one is sufficient: structured CSV import, online discovery that downloads linked PDFs and images from public sources, and an OCR path that prepares scanned papers for review using local tools only. On top of the corpus: model answers, an answer rubric, practice sets, a question workbench, a prompt lab for iterating on the scoring prompts themselves, and a source-health page for spotting a feed that has quietly stopped returning anything.

Crawls, rescores and ingestion run through an app-safe background job runner so the workspace stays usable while a crawl is in flight.

Outcome

A daily current-affairs workflow that cost an hour of triage now arrives pre-filtered, syllabus-mapped, scored, and exportable as a study pack — on free and local models, with the paid path switched off.
