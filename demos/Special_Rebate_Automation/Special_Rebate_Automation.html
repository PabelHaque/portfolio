2 · Extraction

Each attachment is opened with the same structure as the master file: sheet "Special Rebate", rows 1–5 are a title block, data starts at row 6. A row is extracted only if both Member ID (col G) and Rebate Amount (col H) are populated — otherwise it's silently skipped. src/attachment_extractor.py, BR-005, BR-010

BR-006 Member ID normalization: Bengali digits → ASCII; purely numeric IDs are zero-padded to 8 digits; alphanumeric IDs (e.g. a trailing letter suffix) are kept as-is and later skipped by Microzen (BR-017).
BR-007 Mobile normalization: strip non-digits; "880…"(13) → "0…"; "88…"(12) → "0…".
BR-009 (documented, not simulated here) — sheet discovery falls back through 5 strategies, and any additional sheet sharing the same column structure (e.g. a zone's "special Case" sheet) is auto-included.

3 · Duplicate Check

A row is a duplicate if the key member_id|rebate_amount already exists in the master file, the audit database, or earlier in this same batch. Duplicates are logged but never proceed to Microzen or the master file. src/duplicate_checker.py, BR-011, KPI-011

4 · Microzen Verification

For each unique row, the bot logs into Microzen (leading zeros stripped from the member ID for the profile URL), opens the member's last loan, and reads the disbursement date and পরের স্থিতি (post-transaction balance) from the first transaction row. Only 8-digit purely numeric IDs are auto-verified. src/microzen_bot.py, BR-017, BR-018, BR-019

Rate limiting (BR-020): 1500 ms between members, 700 ms between loan pages, an 8-second breather every 30 members — simulated here as a quick progress animation, not real timing.

6 · Ineligible Rows Removed

BR-033 — the master Excel file is the client's running record of who has actually received the rebate SMS. It receives only ELIGIBLE members. NOT_ELIGIBLE and ERROR rows are never written there — they stay fully queryable in the audit database and in the ICT report's "Not Eligible" / "Processing Errors" sheets. This superseded the original REQ-000 baseline, which appended every row before eligibility was known. requirements/REQ-001-master-file-eligible-only.md
