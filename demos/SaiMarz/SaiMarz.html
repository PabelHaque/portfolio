Saved setup

A default setup makes the Files page offer Quick Run - one file dialog, then read and check with no other clicks.

Your data stays on your machine. SaiMarz makes no network calls at any point. There is no telemetry, no update check, no cloud anything. It works with the network cable pulled out.
This page keeps the same rule: everything runs inside your browser, a dropped workbook never leaves it, and the only download is the SheetJS script from jsDelivr that reads and writes .xlsx files.

Join many files on one key

  

    
Join or total many files on one column - twelve months of a loan side by side, or a total per branch per month.

    
Batch runs ONE recipe over many PAIRS and writes one file per pair; this takes many FILES and writes one file. In the desktop app this window reads its own files and needs no recipe; in this page it is shown for orientation - the two-file merge above is the working flow.
